## 🚀 Requisitos Previos

Antes de ejecutar la aplicación, asegúrate de tener instalado:
* [Node.js](https://nodejs.org/) (Versión 16 o superior recomendada)
* Un gestor de paquetes como `npm` (viene incluido con Node)

---

## 🛠️ Tecnologías y Dependencias Utilizadas

### Frontend (Single Page Application)
* **React** (Vite) - Arquitectura basada en componentes.
* **React Router Dom** - Gestión de enrutado dinámico y protección de vistas según rol.
* **React Bootstrap / Bootstrap 5** - Maquetación y estilos responsivos.
* **React Context** - Manejo del estado global de autenticación (`AuthContext`) y cambio de tema claro/oscuro (`ThemeContext`).

### Backend (API REST)
* **Node.js & Express** - Servidor para la lógica de negocio y endpoints.
* **JSON Web Tokens (JWT)** - Autenticación segura y encriptación de sesiones.
* **CORS** - Middleware para permitir peticiones entre entornos de desarrollo cruzados.
